# 原始采访总结稿

这里保存各实践站点尚未发布的原始采访总结稿，不会被 Vite 打包到网站中。

## 存放方式

1. 进入与站点 `id` 同名的子目录。
2. 将总结稿保存为 Markdown、Word 或纯文本文件；建议文件名包含采访日期和版本，例如 `2026-07-28-summary-v1.md`。
3. 原始稿完成事实核对、受访者确认、授权和隐私检查后，再整理为 `src/content/index.js` 中对应站点的 `interviews` 条目。
4. 不要提交含联系方式、账号凭据、未脱敏个人信息或未经授权逐字稿的文件。

`README.md` 仅用于保留目录和说明用途，实际原稿请与说明文件并列存放。
