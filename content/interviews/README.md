# 原始采访总结稿

这里保存各实践站点的采访资料与匿名化发布稿。

## 存放方式

1. 每个站点使用与 `practiceSites[].id` 一致的子目录。
2. 原始 Word 稿统一使用英文文件名，作为本地档案保存；`.gitignore` 会阻止 `docx` 进入公开仓库。
3. 网页发布稿统一命名为 `interview-article.md`，使用 frontmatter、导语、二级标题与结语引文组织内容。
4. 发布稿必须隐去私人姓名、联系方式和可识别未成年人身份的细节；学校、城市、走访日期及公开教育场所可合理保留。
5. `src/content/interviewArticles.js` 会在构建时读取并校验所有发布稿，再将文章接入对应站点。

原始稿与发布稿并列存放，但只有匿名化后的 Markdown 发布稿进入版本库和网站。
